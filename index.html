Hide & Seek3D 多人捉迷藏

A multiplayer 3D hide-and-seek game. A WebSocket server keeps every player’s position in sync while a Tkinter launcher collects your name, the server address and your player colour — then drops you into the Ursina world with real-time shadows. 多人 3D 捉迷藏游戏。WebSocket 服务端实时同步每个玩家的位置；客户端先用 Tkinter 启动器让你填名字、服务器地址、挑一个角色颜色，然后进入带实时阴影的 Ursina 场景。

Auto Citation Generator自动引用生成器

Give it a paragraph and it works out what kind of writing it is — argumentative essay, news article, blog post — then generates the Google queries you’d need to source it. Selenium drives the classification; every run is logged. MIT licensed. 丢给它一段文字，它先判断这属于哪一类写作（论说文、新闻报道、博客等），再生成对应的 Google 检索式，帮你找到可以引用的来源。分类由 Selenium 驱动完成，每次运行都写日志。MIT 协议开源。

AI Prompt Helper提示词管理器

A small prompt library for ChatGPT and DeepSeek. Modifier lines live in three tiers — standard, ultra, academic — and you add, delete and list them from the command line without ever opening the JSON. 给 ChatGPT 和 DeepSeek 用的小型提示词库。修饰语按 standard / ultra / academic 三档分类存放，命令行里就能增、删、查，不用手动去改 JSON 文件。

A web cooking assistant: say what’s in the kitchen, get something worth making. Django on the back, recipes in SQLite, and a one-command launcher so it starts without the usual manage.py incantation. 网页版做饭助手：告诉它冰箱里有什么，它给你一道值得做的菜。后端用 Django，菜谱存在 SQLite 里，还写了一个一行命令就能启动的脚本，不用每次背 manage.py 那串参数。
